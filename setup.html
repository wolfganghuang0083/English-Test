2貼到 Google Apps Script

開啟 Google Apps Script ↗
  1. 用你的 Google 帳號登入（就是放試算表的那個帳號）。
  2. 如果畫面說不支援手機：在 Safari 網址列左邊點 「ㄚA」（或 Chrome 右上角 ⋮）→ 選「要求桌面版網站」。
  3. 編輯區裡原本有一小段 function myFunction()…，長按 → 全選 → 貼上，把它整個換掉。
  4. 按上方的 💾 儲存（專案名稱可以改成「英文小考後台」）。

3發布成網址

  1. 按右上角藍色的 「部署」→「新增部署作業」。
  2. 點左邊的 ⚙️ 齒輪 → 選「網頁應用程式」。
  3. 「誰可以存取」選 「所有人」，按 「部署」。
  4. 要求授權時：選你的帳號 → 看到「Google 尚未驗證這個應用程式」就點 「進階」→「前往…（不安全）」→「允許」。這是你自己的程式，所以 Google 會這樣提醒。
  5. 最後會出現「網頁應用程式網址」（https://script.google.com/macros/s/…/exec），按「複製」。
